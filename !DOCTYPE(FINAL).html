System Integration Architecture

Data Ingestion (Read Layer)

DG Comms connects to the Digital Gateway API using OAuth2 (Azure AD) authentication. This read-only access fetches real-time engagement data from the Digital Gateway-DB to populate the Compliance Tracker and Executive Dashboards.

Document Links (Jump Layer)

Instead of replicating files, the PBC dashboard uses Microsoft Graph API to construct direct, deep-linked URLs. Clicking [DG Docs] jumps the user directly into the secure SharePoint Online (SPO) environment where the file lives.

Status Syncing (Write Layer)

When a manager updates a status in the Compliance Tracker, DG Comms makes a POST request back to the Digital Gateway API. This ensures the central database is updated in real-time. Ticketing integration relies on ServiceNow REST APIs.

Communications (Hub Layer)

The chat interface leverages the Microsoft ecosystem. Conversations mapped to specific entities (e.g., `# Alpha Fund I Team`) can be mirrored as real Microsoft Teams channels, ensuring cross-platform visibility without data silos.
